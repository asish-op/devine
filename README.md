# Divine Luxury Properties

Premium multi-page real estate website for Divine Luxury Properties, built with Next.js 16, React 19 and the Cloudflare-compatible vinext runtime.

## Local development

```bash
npm install
npm run dev
```

## Production validation

```bash
npm run build
npm test
```

The site includes property and developer profiles, services, careers, insights, contact and enquiry flows, a downloadable project brochure, and responsive navigation.
